# Contributing

1. Fork the repository and create a focused branch.
2. Run `mvn clean verify` before opening a pull request.
3. Add tests for behavior changes and bug fixes.
4. Preserve the 2.x public API unless the change is explicitly approved as breaking.
5. Do not commit database passwords, generated classes, IDE metadata, or third-party JAR files.

Use conventional, descriptive commits such as `fix: close result sets reliably`.
